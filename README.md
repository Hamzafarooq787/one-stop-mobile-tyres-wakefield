# One Stop Mobile Tyre Wakefield

Next.js (App Router) website for One Stop Mobile Tyre Wakefield, a 24/7 mobile
tyre fitting service. Converted from the original static HTML page designs
into a multi-page Next.js site with a shared header/footer, Tailwind CSS v4
theme ("Midnight Kinetic" — dark, glassmorphic, electric orange accents), and
`lucide-react` icons.

## Pages

- `/` — Home (hero, services overview, why-choose-us, process, coverage,
  gallery preview, reviews, FAQ, CTA)
- `/services` — Full service list with pricing
- `/coverage-areas` — Coverage zones and sectors across West Yorkshire
- `/gallery` — Photo gallery grid
- `/about` — Company story, values, and lead technician profile
- `/contact` — Contact form, direct lines, and map card

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run start` — run the production build
- `npm run lint` — run ESLint
